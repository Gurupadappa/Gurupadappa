**HTTPS / TLS Cryptographic Compliance Automation**

A security automation project focused on evaluating web-server cryptographic configurations against **ITSAR Clause 2.11.1** requirements.

```text
Target
  ↓
TLS Configuration Analysis
  ↓
TLS 1.0 / 1.1 Validation
  ↓
```

### 🧠 SecureRAG

**RAG Poisoning Detection & Defense Framework**

A research-oriented cybersecurity project exploring attacks against **Retrieval-Augmented Generation systems**.

The framework focuses on identifying suspicious retrieved documents using multiple security signals.

```text
User Query
    ↓
Retriever
    ↓
Retrieved Documents
    ↓
┌─────────────────────────────┐
│ Security Analysis           │
│                             │
│ • Semantic Analysis         │
│ • Instruction Analysis      │
│ • Relevance                 │
│ • Provenance                │
│ • Consistency               │
│ • Contradiction Detection   │
└─────────────────────────────┘
    ↓
Risk Score
    ↓
Quarantine / Allow
    ↓
Grounded Response Validation
```

**Focus**

`AI Security` `LLM Security` `RAG Security` `Data Poisoning` `Prompt Injection` `Python`
